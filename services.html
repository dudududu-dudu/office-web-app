一、相续 / 遗嘱 / 继承相关

涵盖日本国内不动产继承、遗产分割、法定相续信息取得、遗嘱制作等。若涉及国际继承（外国籍、多国资产/继承人），请查看国际继承专页。

  • 相续登记（不动产名义变更、资料准备、申请）
  • 遗产分割协议书制作（仅不动产/含其他遗产）
  • 法定相续信息一览图制作（含实费）
  • 遗嘱制作（自笔/公证）、公证立会、证人安排
  • 遗嘱保管制度利用手续

二、不动产登记

外国人购买、出售、赠与、相续日本不动产时的登记手续，以及相关合同文书制作支持。

  • 所有权保存登记
  • 所有权移转登记（买卖：买方 / 贈与・财产分与等）
  • （卖方）结算文件制作等附随业务
  • 登记名义人表示变更
  • （根）抵当权设定 / 抹消
  • 合同书作成（买卖/赠与）*随登记申请的情形
  • 住宅家屋证明书取得、评价证明书取得等

三、公司设立 / 商业登记

在日本设立公司、变更登记、解散清算等手续。大阪为据点，可全国対応（按个案确认）。

  • 株式会社设立登记、合同会社设立登记
  • 组织变更设立（合同会社→株式会社等）
  • 公司/合同会社譲渡（股权/持分譲渡相关登记）
  • 役员变更、本店移转、商号/目的变更等
  • 募集股份发行（现物/现金增资）
  • 公司解散（解散、清算人选任、清算结了）
  • 外国公司事务所/营业所设立

四、归化 / 在留资格 / 各类许可

日本国籍取得（归化）与在留相关手续，以及外国人开展业务可能涉及的各类许可申请支持。

  • 归化申请（资料整理、书类作成、面接对策等）
  • 在留资格申请/更新（经营管理、技人国、永住许可等）
  • 各类许可（如饮食店营业许可、古物商许可、建设业许可等）
  • 法院提交文件作成（相续放弃申述书、特别代理人选任申请等）
  • 其他生活相关法律困扰咨询（以可对应范围为准）
